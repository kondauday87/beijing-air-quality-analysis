## Dataset

The dataset contains hourly air quality measurements collected from selected Beijing monitoring stations between 2013 and 2017.

### Urban Monitoring Stations
- Dongsi
- Guanyuan

### Suburban Monitoring Stations
- Changping
- Huairou

The analysis was conducted using the following dataset files:
- PRSA_Data_Dongsi_20130301-20170228.csv
- PRSA_Data_Guanyuan_20130301-20170228.csv
- PRSA_Data_Changping_20130301-20170228.csv
- PRSA_Data_Huairou_20130301-20170228.csv

Variables include:
- PM2.5
- PM10
- SO2
- NO2
- O3
- Temperature
- Wind Speed
- Rainfall
