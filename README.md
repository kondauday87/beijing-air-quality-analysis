# Beijing Air Quality Analysis

## Project Overview
This project analyses Beijing air quality data collected from multiple monitoring stations between 2013 and 2017. The analysis focuses on PM2.5 pollution trends, seasonal variations, meteorological relationships, and machine learning-based prediction models.

The project was developed as part of the CMP7005 Practical Data Analysis coursework.

---

## Objectives
- Analyse PM2.5 air pollution trends in Beijing
- Compare pollution levels across urban and suburban stations
- Explore relationships between temperature and air quality
- Build and evaluate machine learning prediction models
- Develop an interactive GUI application for data exploration

---

## Dataset
The dataset contains hourly air quality measurements collected from Beijing monitoring stations including:
- Dongsi
- Guanyuan
- Changping
- Huairou

Variables include:
- PM2.5
- PM10
- SO2
- NO2
- O3
- Temperature
- Wind Speed
- Rainfall
